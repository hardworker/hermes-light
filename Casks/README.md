# Homebrew cask

`hermes-light.rb` installs the signed and Apple-notarized Apple Silicon client.
It is generated by `scripts/light_client_release.py publish` only after
notarization, stapling, Gatekeeper validation, and final archive checksum checks.

```sh
brew tap hardworker/hermes-light https://github.com/hardworker/hermes-light
brew trust --cask hardworker/hermes-light/hermes-light
brew install --cask hardworker/hermes-light/hermes-light
```

The cask downloads the Light client directly; no local agent runtime or
bootstrap installer is included.
